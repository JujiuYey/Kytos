# 角色表情生成 · Few-shot 模板

本文件提供聊天模型在生成 `[EXPRESSION DETAILS]` 描述时的 few-shot 示例与填空模板。

## 1. 6 槽填空模板

```
[情绪强度] <mild | moderate | strong>
[眉部] <具体眉部动作>
[眼部] <睁闭 + 视线方向 + 任何特殊光感>
[嘴部] <唇形 + 开合 + 嘴角方向>
[面部肌肉] <颧骨/脸颊/下颌/咬肌变化>
[姿态] <头部或上半身轻微姿态>
```

## 2. 标准示例（直接可仿写）

### 微笑

```
moderate 强度的温柔微笑。眉头自然舒展，眉尾微松。双眼微眯带笑意，
视线平视镜头，眼角有自然的细纹。嘴唇轻闭，嘴角自然上扬约 15 度，
下唇微微放松。颧骨轻度上提带动脸颊柔和隆起，下颌线条柔和。
头部正直，肩膀放松。
```

### 愤怒

```
strong 强度的愤怒表情。眉心紧锁形成川字纹，眉尾向下压，眉骨上方
肌肉明显隆起。上眼睑下压露出较少虹膜，瞳孔聚焦前方，目光锐利且
稳定。嘴唇紧闭，上唇略微上提露出紧绷的牙关，下唇向内抿。
咬肌与颞肌明显鼓起，鼻翼两侧加深法令纹。头部微微前倾，下巴
略微收紧，肩膀绷紧上抬。
```

### 沉思

```
mild 强度的沉思表情。眉头轻蹙但未形成明显纹路，眉尾略向下。双眼
半开半合，视线偏向画面左下方约 30 度，目光略微失焦。嘴唇自然
闭合，嘴角水平，未表现出明显的情绪倾向。下颌与脸颊肌肉放松。
头部微微向视线方向倾斜约 10 度，肩膀自然下垂。
```

### 惊讶

```
moderate 强度的惊讶表情。眉毛整体上抬，眉峰明显拉高，眉间皮肤
舒展。双眼睁大，上眼睑显著提升露出完整虹膜，瞳孔略微放大，
视线直对镜头。嘴唇自然张开呈小 O 形，上下唇之间留有缝隙，
不露齿。脸颊肌肉向上拉伸，鼻翼轻微外扩。头部轻微后仰约 5 度，
颈线拉直，肩膀轻微耸起。
```

### 悲伤

```
moderate 强度的悲伤表情。眉头内侧上挑形成八字眉，眉尾下垂。
上眼睑下垂覆盖虹膜上缘，眼下区域轻微浮肿，眼角微收，无泪光。
嘴唇轻闭，嘴角明显下拉约 20 度，下唇微微前突。脸颊肌肉
松弛略向下，鼻翼两侧法令纹加深。头部微微前倾并低垂，
肩膀向内收拢。
```

## 3. 反例（避免出现）

### 反例 A：模糊形容词堆砌

```
非常非常高兴的表情，看起来特别开心，给人一种非常愉悦的感觉。
```

问题：无具体五官动作锚点，模型无法还原。

### 反例 B：复述身份 / 服装

```
moderate 强度的高兴表情。眉部放松。这位身穿黑色外套的银发年轻女性
双眼微眯，视线看向镜头，嘴角上扬。她的头发在风中飘动。
```

问题：服装、发型、年龄、性别已在参考图中，重复声明会触发模型重新设计外观，导致与参考图漂移。

### 反例 C：描述画风 / 比例 / 媒介

```
moderate 强度的高兴表情。眉部放松，参考图风格保持一致。双眼微眯。
竖屏 1024x1536 输出。电影级调色。嘴角上扬。
```

问题：画风由参考图决定，比例 / 分辨率是工程参数，不应出现在表情描述里。

## 4. 长度的硬约束

`buildExpressionPrompt` 把这段描述作为 `[EXPRESSION DETAILS]` 嵌入 gpt-image-2 prompt，APIMart 端 max 总长度有上限。本项目 `MAX_PROMPT_LENGTH` 约为 20,000 字符，因此 `[EXPRESSION DETAILS]` 控制在 80~180 中文字符最稳。超过 250 字符往往会触发模型裁剪或忽略。

## 5. 何时使用 strong

`strong` 表情仅适用于：

- 愤怒到咬牙切齿
- 惊讶到惊呼
- 恐惧到退缩
- 狂喜到笑出眼泪
- 悲伤到落泪

日常情绪默认 `moderate`。任何带"轻微"、"微微"、"似乎"的描述都应是 `mild`。
