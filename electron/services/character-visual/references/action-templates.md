# 角色动作生成 · Few-shot 模板

本文件提供聊天模型在生成 `[TARGET ACTION]` 描述时的 few-shot 示例与填空模板。

## 1. 8 槽填空模板

```
[身体朝向] <正面/侧面/3/4 侧/背面>
[重心] <居中/前倾/后倾/偏向一侧>
[躯干] <直立/前倾/后仰/侧弯/扭转>
[头部] <正直/前倾/侧倾/扭转>
[手臂] <自然下垂/举起/前伸/交叉/抱胸/摆动>
[手势] <握拳/张开/持物/自然弯曲/指向某方向>
[腿部] <并拢/分开/一前一后/弓步/蹲姿>
[脚步] <平踏/前掌/后跟/踮脚/跳跃>
```

## 2. 标准示例（直接可仿写）

### 行走

```
身体 3/4 侧朝镜头。重心略前倾。躯干基本直立伴随自然的行走扭转。
头部正直视线平视前方。左臂前摆右臂后摆。手势自然弯曲手指微拢。
右腿在前膝微屈，左腿在后接近伸直。左脚前掌着地右脚后跟抬起正要离地。
```

### 双手举过头顶欢呼

```
身体正面朝向镜头。重心居中略偏后。躯干轻微后仰。头部后仰视线
朝向上方。双臂高举过头伸直。双手张开五指分开呈欢呼手势。
双腿并拢站立。双脚平踏地面脚尖略微外开。
```

### 蹲下拾取

```
身体侧面朝镜头。重心明显前移至双脚。躯干前倾约 45 度。头部
前倾视线向下看物体。双臂自然下垂前伸。双手张开手指自然弯曲
准备抓握。双腿大幅弯曲呈深蹲姿势。双脚平踏地面间距与肩同宽。
```

### 持剑向前刺

```
身体 3/4 侧朝镜头。重心前倾至前脚。躯干略前倾并向出剑方向
扭转。头部正直视线沿剑尖方向。持剑手前伸手臂几乎完全伸展
呈直线刺出。后手屈肘收于胸前呈握护手姿态。前腿微屈承重，
后腿蹬直后撑。前脚平踏后脚前掌蹬地。
```

### 静坐阅读

```
身体正面。重心稳坐在椅面。躯干直立微前倾。头部略低视线向下
落于手中书本。双臂屈肘前举。双手分持书本两侧。双腿自然弯曲
呈 90 度。双脚平踏地面。
```

### 跑步冲刺

```
身体侧面。重心显著前倾几乎与地面平行。躯干前倾。头部抬起
视线朝前方。双臂屈肘约 90 度大幅前后摆动。双手松握半握拳。
双腿大幅前后展开。前腿蹬直后摆，后腿屈膝前抬接近水平。
前脚刚刚着地后脚完全离地。
```

## 3. 反例（避免出现）

### 反例 A：模糊动词

```
他正在跑步。
```

问题：无具体肢体动作锚点，模型无法还原。

### 反例 B：复述身份 / 服装

```
3/4 侧朝镜头。这位身穿黑色外套的银发年轻男性重心前倾。
他的头发在风中飘动。躯干前倾。…
```

问题：服装、发型、年龄、性别已在参考图中，重复声明会触发模型重新设计外观，导致与参考图漂移。

### 反例 C：引入表情 / 视线变化

```
身体 3/4 侧朝镜头。重心前倾。躯干前倾。头部前倾。
双眼紧盯前方露出愤怒的眼神，眉头紧锁。…
```

问题：动作图表情不变（本项目规则），表情变化会扩散到五官导致参考图漂移。

### 反例 D：描述画风 / 比例 / 媒介

```
3/4 侧朝镜头。参考图风格保持一致。横屏输出。电影级调色。
重心前倾。…
```

问题：画风由参考图决定，比例 / 分辨率是工程参数，不应出现在动作描述里。

### 反例 E：违反人体结构

```
身体 3/4 侧朝镜头。重心居中。躯干笔直。头部反向扭转 180 度
看向身后。…
```

问题：头部扭转超过 90 度违反人体生理极限，模型会输出扭曲或拒绝绘制。

## 4. 长度的硬约束

`buildCharacterActionPrompt` 把这段描述作为 `[TARGET ACTION]` 嵌入 gpt-image-2 prompt。APIMart 端 max 总长度有上限。本项目 `MAX_CHARACTER_ACTION_LENGTH` 约为 2000 字符，因此 `[TARGET ACTION]` 控制在 80~180 中文字符最稳。超过 250 字符往往会触发模型裁剪或忽略。

## 5. 何时增加细节

当用户描述中包含明确的方向 / 程度词时（如"向前大步跑"、"高举双手过头"、"深蹲"），8 槽全部展开。当描述模糊时（如"随意站着"），前 4 槽 + 后 2 槽足够，中间的 arm / hand 可一句话概括。

## 6. 视线与表情的边界

动作图**保持**原表情（参考图的表情）。即使描述中出现"惊讶地跑"或"笑着招手"，动作描述只描述肢体，**不**描述表情变化。表情变化属表情模块职责，不属动作模块。
