# 模型与凭据

Kytos 不从项目根目录的 `.env` 读取用户 API Key。所有模型凭据都应在“系统设置 → 模型厂商”中配置。

## 支持的厂商

| 厂商     | 当前用途                                   | 对应模型                           |
| -------- | ------------------------------------------ | ---------------------------------- |
| APIMart  | 角色锚点动作、表情、插画和故事分镜图片生成 | GPT-Image-2                        |
| DeepSeek | 插画、故事共创和提示词整理                 | DeepSeek V4 Flash、DeepSeek V4 Pro |
| MiniMax  | 文本与多模态共创任务                       | MiniMax M3                         |

![系统设置页面](../images/screenshots/08-settings.png)

## 三类默认模型

### 通用模型

用于插画和故事共创等主要对话任务。角色创建当前只负责填写名称并上传已有角色锚点，不会从这里发起 AI 角色生成。

MiniMax M3 当前标记为支持图片输入；DeepSeek V4 Flash 和 DeepSeek V4 Pro 当前不支持图片输入。页面会根据模型能力决定是否允许把图片作为对话附件发送。

### 快速模型

用于动作、表情等短提示词生成，优先考虑响应速度。配置表情或动作提示词时，如果对应厂商的凭据缺失，界面会阻止发起请求并给出配置提示。

### 生图模型

当前生图模型为 GPT-Image-2，通过 APIMart 发起图片生成任务。生成是明确的人工操作，页面会显示提交、等待、处理中、完成或失败状态。

## 凭据如何保存

API Key 会在 Electron 主进程中通过系统安全存储加密，然后写入应用级 SQLite 数据库。渲染端只能查询“是否已经配置”，不会取回明文 Key。

这意味着：

- API Key 不会写入作品工作区。
- API Key 不会保存在仓库 `.env` 文件中。
- API Key 不会通过 `window.desktop` 返回给 Vue 页面。
- 系统安全存储不可用时，应用会拒绝保存或读取 Key。

## 更换或删除凭据

在对应厂商设置中可以覆盖已有 Key 或删除凭据。删除后，依赖该厂商的生成与对话任务将不可用，但已经保存在本地工作区的作品不会受到影响。
