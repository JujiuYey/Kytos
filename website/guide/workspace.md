# 工作区与数据

Kytos 将“不随作品切换的应用设置”和“属于当前作品空间的数据”分开保存。

## 应用级数据

Electron 用户数据目录中保存 `kytos-app.sqlite3`，主要包含：

- 当前工作区路径
- 明暗主题
- 通用、快速和生图模型选择
- 经过系统安全存储加密的 API Key

该数据库不在用户选择的作品工作区内。不同操作系统的 Electron 用户数据目录位置不同，应通过系统或 Electron 提供的目录定位方式访问，不要在代码中假定固定路径。

## 工作区数据

用户选择的目录中包含：

```text
Kytos/
├── kytos.sqlite3
└── assets/
    ├── character-candidates/
    ├── character-expressions/
    ├── character-portraits/
    ├── character-sheets/
    ├── illustrations/
    └── story-frames/
```

`kytos.sqlite3` 保存角色、视觉资产记录、生成任务、插画主题、故事和分镜等结构化数据。`assets/` 保存实际图片文件。

部分目录名保留了历史命名，例如 `character-portraits` 和 `character-sheets`。界面已经统一使用“角色锚点”和“参考板”等名称，但为了兼容已有工作区，不应手动重命名历史目录。

## 切换工作区

在“系统设置 → 基本配置”中可以选择其他目录。切换时 Kytos 会：

1. 检查新目录是否可写。
2. 创建缺少的 `assets/` 目录。
3. 关闭旧工作区数据库连接。
4. 加载或初始化新目录中的 `kytos.sqlite3`。

旧目录不会被移动或删除。切回原路径即可重新读取原工作区。

## 导出图片

系统设置提供工作区图片批量导出。导出时会扫描 `assets/`，并按照角色候选、角色锚点、角色参考板、角色表情、插画和故事分镜整理到一个新的时间戳目录中。

导出操作复制图片，不会修改原工作区的数据和文件。

## 备份建议

需要完整备份时，应同时复制 `kytos.sqlite3` 和 `assets/`。只复制图片可以保留成品，但会丢失角色关系、生成记录、版本选择和故事结构等信息。
