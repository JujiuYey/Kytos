# 插画创作

插画工作区把对话、结构化创作 brief、参考图片和生成版本放在同一个流程中。

## 创建插画主题

1. 打开“插画创作”。
2. 新建或选择一个创作主题。
3. 在对话中描述主体、环境、动作、构图、氛围和风格。
4. 让共创助手整理 brief 和最终提示词。
5. 选择画面比例、清晰度和参考图片。
6. 明确触发图片生成。

通用模型负责共创对话，生图模型负责最终图片任务。两者可能依赖不同厂商的 API Key。

![插画创作页面](../../docs/screenshots/05-illustration-create.png)

## 组合参考素材

参考选择器会汇总当前工作区中可用的素材：

- 角色正式视觉
- 角色表情
- 已上传插画
- 已完成的插画版本

角色素材主要用于维持人物身份与外观；已有插画也可以作为内容或风格参考。选择参考图后，生成请求会读取对应的本地文件，由主进程发送给模型服务。

## 管理生成版本

每次生成都会成为主题中的一个版本。版本会显示提交、等待、处理中、完成或失败状态。

完成后可以：

- 查看版本图片。
- 选择当前版本。
- 基于已有版本继续修改。
- 删除不再需要的版本。

修订不会覆盖原始图片，而是生成新的版本记录，因此可以在不同方向之间切换。

## 插画管理

“插画管理”用于集中查看工作区内的插画资源，包括生成结果和手动上传内容。这里适合执行上传、浏览、整理和删除操作；具体主题的对话与版本演进仍在“插画创作”中完成。

![插画管理页面](../../docs/screenshots/06-illustration-library.png)

## 画布工作流 Beta

“插画创作 Beta”提供基于节点画布的实验性流程。它与稳定插画工作区并存，交互和数据结构仍可能调整，不建议把唯一创作记录只保存在实验流程中。
