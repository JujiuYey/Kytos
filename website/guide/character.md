# 角色与锚点资产

角色是 Kytos 的核心创作对象。角色资料、正式锚点、动作图片和表情可以继续作为插画与故事创作的参考素材。

## 创建第一个角色

“创建角色”只负责建立角色概要并上传已有角色锚点：

1. **填写名称**：确认角色名称。
2. **上传锚点**：选择一张已有角色图片。
3. **完成创建**：保存后进入角色管理。

上传的图片会直接保存为角色的正式锚点资产。

![创建角色页面](/docs/screenshots/02-character-create.png)

## 管理多个角色

“角色管理”用于：

- 查看当前工作区中的全部角色。
- 切换当前角色。
- 修改角色名称。
- 新建或移除角色。

移除角色时，角色会从管理列表中删除。为了避免破坏旧作品，已经生成的图片文件会保留在工作区。

![角色管理页面](/docs/screenshots/03-character-library.png)

## 管理正式锚点

“角色锚点”集中管理某个角色的图片资产：

- 上传已有角色图片。
- 生成指定动作。
- 生成角色参考板。
- 重命名或删除图片。
- 将图片加入或移出正式资产。

正式资产是后续创作的优先角色参考。准备插画参考图时，Kytos 会从正式锚点中提供可选素材。

![角色锚点与表情页面](/docs/screenshots/04-character-assets.png)

::: tip 正式资产是一条明确边界
不是每张生成结果都会自动代表角色。先挑选并设为正式资产，再把它用于后续插画，可以减少角色外观漂移。
:::

## 创建角色表情

“表情管理”支持生成和上传两种来源：

1. 选择角色正式锚点或已有表情作为参考。
2. 输入表情名称和提示词，或让快速模型生成提示词。
3. 选择输出规格后发起图片生成。
4. 在任务完成后重命名、查看或删除结果。

表情资产会出现在插画参考选择器中，可以和正式角色锚点一起参与新的创作。

## 图片编辑

从支持编辑的图片入口可以进入“图片编辑”。该页面用于对工作区图片进行背景和图像处理，处理结果仍应通过明确保存操作写回工作区。
