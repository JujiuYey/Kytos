# 常见问题

## 无法完成首次设置

确认所选路径是绝对路径，并且当前用户拥有创建目录和写入文件的权限。Kytos 会在设置时写入一个临时探测文件；操作系统拒绝写入时，目录不会被保存。

## 页面提示尚未配置 API Key

检查当前任务实际使用的模型：

- 图片生成依赖 APIMart。
- DeepSeek 模型依赖 DeepSeek Key。
- MiniMax M3 依赖 MiniMax Key。

进入“系统设置 → 模型厂商”查看对应厂商是否显示已配置。只配置一个聊天厂商并不会自动满足另一个厂商的模型请求。

## 系统安全存储不可用

Kytos 不会在无法安全加密时降级为明文保存 API Key。请确认应用运行在具有系统凭据存储能力的正常桌面会话中，再重新保存凭据。

## 参考图片不能发送给聊天模型

当前只有标记为支持图片输入的聊天模型会开放多模态附件。可以在“系统设置 → 默认模型”中查看能力标记；截至当前版本，MiniMax M3 支持图片输入。

## 图片任务长时间处于处理中

图片生成是外部异步任务。先保留当前主题或故事，不要重复连续提交相同请求。稍后重新进入页面，Kytos 会从工作区读取任务记录并继续查询状态。

如果任务最终失败，界面会显示服务返回的错误信息。常见原因包括凭据失效、服务额度不足、参考图不可读取或外部服务暂时不可用。

## 切换工作区后作品不见了

切换工作区不会迁移旧数据。重新选择原工作区路径即可恢复原来的角色、插画和故事。需要合并两个工作区时，应先分别备份；当前版本没有自动合并功能。
